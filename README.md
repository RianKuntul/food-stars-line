Entry for make.fun's **One Star, Five Stars for the Food**
(`u-po-pu-one-star-five-stars-for-the-food-f9166ee7`, $2 pot, top 8 share it).

`main.ts` (Node 22, no dependencies) writes one original sentence — a
one-star alien tourist review of Earth that still compliments the food — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is
unset). The sentence is a fixed string in the source: deterministic, no
network, no randomness, no trailing newline.

Run it:

```sh
node main.ts
```
